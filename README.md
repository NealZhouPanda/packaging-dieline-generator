# 包装刀模生成器

一个可离线运行的包装刀模生成器：输入箱体尺寸和纸厚，在浏览器本地计算刀模，导出 1:1 mm SVG 或带信息栏的 PDF。发布文件是单个 HTML，双击即可使用，不需要安装运行环境，也不会上传尺寸数据。

在线试用：<https://nealzhoupanda.github.io/packaging-dieline-generator/>

> 这是一个面向实际打样和生产前核对的辅助工具，不替代纸箱厂的结构确认、试样和工艺审核。

## 当前发布能力

`app/包装刀模生成器.html` 是当前单文件应用源，`release/包装刀模生成器.html` 是由它复制出的交付文件。当前包含四种箱型：

- `0201`：标准纸箱
- `0202A`：普通开槽纸箱
- `E005C`：翻盖飞机盒
- `C001GX`：锁底自扣盒

输入项包括长、宽、高和瓦楞纸厚。界面支持开口方向切换、展开尺寸提示、抛重估算，以及 SVG / PDF 下载。

页面右上角可用 `EN / 中文` 切换主要界面文字；语言层不参与尺寸和刀模计算。

## 重要说明

- 尺寸计算只适用于对应箱型，不能把一种箱型的补偿规则套到另一种箱型。
- 首次投产前必须打样，核对内尺寸、刀模尺寸、纸厚、压痕和成箱效果。
- `0202A` 的几何回归范围已由本地校准快照和自动测试锁定。
- 新增箱型仍需继续补充独立的结构样本和生产验证；开口方向上的用纸数据在未完成校准前会显示「超范围」。
- 材料幅面警示只是生产前提示，不代表所有供应商设备的统一限制。

## 开发

需要 Node.js 和 npm：

```bash
npm ci
npm test
npm run build:offline
```

构建结果：

```text
release/包装刀模生成器.html
```

打开开发页面：

```bash
npm run dev
```

## 目录

- `app/`：当前多箱型单文件应用源，适合直接在 GitHub 上协作修改
- `src/`：模块化几何计算、SVG / PDF 导出和回归测试所用代码
- `tests/`：几何、尺寸、导出和安全门测试
- `reference/0202a-calibration/`：脱离外部服务的本地校准快照，仅用于回归测试
- `tools/`：单文件构建和 PDF 字体子集构建脚本
- `release/`：由 `app/` 生成、可直接转发的离线 HTML
- `CONTRIBUTING.md`：协作和验证要求

## 贡献前提

任何几何规则变更都要同时更新测试，并完成 `npm test` 与 `npm run build:offline`。没有经过打样或独立坐标验证的箱型，不要宣称适用于批量生产。

字体子集使用 Noto Sans SC；其字体许可证见 `LICENSES/OFL-1.1.txt`。
